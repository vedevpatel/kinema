3-5 paired seeds per defect / 50 eval episodes / 20k steps - indicative ordering evidence, not claim-grade. Each injected defect is trained against a clean arm under the same seed; deltas are defect minus clean. Cross-accelerator pairs are confounded, as noted below. Health-score weights (score model tiered-v3) are anchored on these rows where a check has one, two of them capped below their tier; a new table needs a new score-model version (protocol, weights, leaderboard).
